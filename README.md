# BallToday
Premium Dark Sports website for Thai football fans.

## Deploy
Upload all files inside this folder to the root of the `fb55vip/line` repository. Keep `index.html` and `CNAME` at repository root.

## Live API
Set `BallToday.config.apiBase` in `assets/js/app.js` to your serverless API URL. Never expose a provider API key in browser JavaScript.
